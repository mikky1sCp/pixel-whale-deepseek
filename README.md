# 🐳 Pixel Whale для DeepSeek Chat

Пиксельный кит в очках и худи, который живёт в углу чата DeepSeek и реагирует на то, что ты делаешь.

Печатаешь — он думает. Отправил сообщение — прыгает от радости. Надоел — усыпил.

![демо](demo.gif)

## Что умеет

- **idle** — покачивается и пускает пузыри, когда ты ничего не делаешь
- **thinking** — поправляет очки и зажигает лампочку, пока ты печатаешь
- **happy** — подпрыгивает, когда отправляешь сообщение
- **sleep** — прячется по крестику, будится кнопкой в углу

Ещё кит помнит, что ты его усыпил — после перезагрузки страницы он останется спать.

## Установка

1. Ставишь [Tampermonkey](https://www.tampermonkey.net/) (Chrome / Firefox / Edge / Safari — у них есть сборки под всё).
2. Открываешь [страницу на Greasy Fork](ссылка) и жмёшь «Установить».
3. Заходишь на [chat.deepseek.com](https://chat.deepseek.com). Кит уже там.

Если Greasy Fork не работает — можно скачать `.user.js` из [релизов](ссылка) и закинуть в Tampermonkey руками.

## Настройки

Все тайминги лежат в начале скрипта, в блоке `const`:

```js
const IDLE_TIMEOUT  = 10000; // через сколько без ввода кит успокаивается
const HAPPY_TIMEOUT = 2000;  // сколько длится «радость» после Enter
```

Меняешь цифры — сохраняешь — готово.

## Планы

- [x] базовый кит с четырьмя состояниями
- [x] реакция на ввод и Enter

- [ ] клик по киту — он говорит что-нибудь в балуне
- [ ] настройки прямо в интерфейсе, без правки кода
